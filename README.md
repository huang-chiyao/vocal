# VOCAL: Visual Odometry via ContrAstive Learning

Breakthroughs in visual odometry (VO) have revolutionized robotics by enabling precise estimation of camera states, a critical function underpinning a wide range of autonomous systems. However, many learning-based VO methods rely on geometric assumptions that lack interpretability and theoretical grounding in purely data-driven frameworks, thereby limiting their flexibility and integration with complementary models. To address these challenges, we propose VOCAL (Visual Odometry via ContrAstive Learning), a pioneering approach that reformulates VO as a label ranking problem. By integrating Bayesian inference within a representation learning framework, VOCAL organizes visual features to accurately reflect underlying 3D camera states. In our framework, the ranking mechanism ensures that visual inputs from different scenarios with similar camera states yield similar feature representations in the latent space. This alignment produces consistent and spatially meaningful representations across varied scenes and trajectories, enhancing compatibility with multimodal data. Extensive experiments on the KITTI dataset demonstrate VOCAL’s interpretability and flexibility, establishing it as a promising framework for advancing VO with improved spatial intelligence.
